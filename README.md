# Jedidiah Akindele — Portfolio

> A modern, high-performance developer portfolio built with React and Vite, inspired by the aesthetics of [kroszborg.co](https://www.kroszborg.co/).

![Portfolio Preview](public/favicon.svg)

## ⚡ Overview

Personal portfolio of **Jedidiah Akindele**, Systems Engineering graduate and Full Stack & AI Systems Engineer at **Vester**. Highlights hybrid rules + LLM pipelines (classifying 42,000+ startups), predictive time-series modeling (Prophet, ARIMA), local open-weight LLM benchmarking on consumer GPUs, and data-intensive React/TypeScript applications.

---

## ✨ Features

- **Obsidian Dark Aesthetic**: Custom Vanilla CSS design system with glassmorphism, radial gradient glows, and typography from Google Fonts (*Plus Jakarta Sans*, *Hanken Grotesk*, and *JetBrains Mono*).
- **Floating Pill Navigation**: Glassmorphic top-center nav bar with active section spy and `⌘K` Command Palette trigger.
- **Interactive Eye-Tracking Resume Button**: Dual eye pupils that follow the user's cursor in real time via mouse coordinate calculations, triggering celebratory confetti on click and opening a printable resume modal.
- **Accordion Work Experience**: Expandable cards with tech tool badges and bold quantitative highlights (Vester, New Horizons, Freelance Dev, Technical Writing).
- **Featured Projects & Architecture Modals**: Filterable showcase (*AI & ML*, *Data Science*, *Full Stack*) with deep-dive problem/solution/impact architecture modals.
- **Journey & Gears Tab**: Interactive milestone timeline (B.Sc. & Diploma in Systems Engineering at University of Lagos) and workstation hardware breakdown (Skytech Gaming PC, AMD Radeon RX 9070 XT, AMD Ryzen 7 7700).
- **Embedded Portfolio AI Assistant**: Floating bottom-right chat drawer with conversational Q&A on projects, ML models, and contact information.
- **Command Palette (`Ctrl + K` / `⌘K`)**: Fast keyboard-driven navigation across sections and quick-copy contact actions.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/akinjed5/portfolio.git

# Navigate into directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
